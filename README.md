02 · Featured Engineering Project

Intelligent QA Automation Ecosystem

Engineering graduation project developed at Webify Technology.

A reusable QA ecosystem that automates the validation of Jira tickets by orchestrating web and mobile tests, collecting execution evidence, and updating the ticket with the final result.

Jira ticket → n8n orchestration → AI-assisted analysis
            → Playwright / Appium execution
            → Allure evidence → Jira result update

Key engineering contributions

Automated web testing with Playwright + TypeScript and mobile testing with Appium.

Structured reusable scenarios using BDD/Gherkin, POM, and business flows.

Connected Jira and n8n to trigger tests and update defects automatically.

Integrated Allure reporting, Docker, GitLab CI/CD, and an LLM-based QA agent.
