Featured engineering project

Intelligent QA Automation Ecosystem

Engineering graduation project developed at Webify Technology.

A reusable QA ecosystem that analyzes Jira tickets, triggers the relevant web or mobile automated tests, collects execution evidence, and updates the ticket with a traceable verdict.

flowchart LR
    A[Jira ticket] --> B[n8n orchestration]
    B --> C[AI-assisted analysis]

    D -->|Web| E[Playwright + TypeScript]
    D -->|Mobile| F[Appium]
    E --> G[BDD / POM execution]
    F --> G
    G --> H[Allure evidence]
    H --> I[Jira verdict update]
