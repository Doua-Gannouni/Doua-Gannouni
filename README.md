<h1>🚀 Featured Engineering Project</h1>

<h2>Intelligent QA Automation Ecosystem</h2>

> Engineering Graduation Project · Webify Technology

A reusable QA ecosystem that automates Jira ticket validation through web and mobile tests, reporting and AI-assisted analysis.

```text
Jira → n8n → AI QA Agent → Playwright / Appium → Allure → Jira Update
```

### Key contributions

- Automated web tests with **Playwright + TypeScript** and mobile tests with **Appium**.
- Structured reusable scenarios using **BDD/Gherkin, POM and business flows**.
- Triggered test execution and Jira updates through **Jira API + n8n**.
- Generated traceable test evidence with **Allure, Docker and GitLab CI/CD**.
